# Grand Canyon University

## Overview

Jamie Reichenberger served as a Subject Matter Expert and curriculum consultant for Grand Canyon University’s College of Engineering and Technology.

In this role, Jamie contributed to the design and development of undergraduate and graduate degree programs related to game development, game design, and human-computer interaction.

Her work included creating degree-level course maps, helping define program architecture, developing individual course concepts, writing course-level requirements, and collaborating with academic stakeholders to align technical content with program outcomes.

Jamie supported curriculum development for:

- Bachelor of Science in Game Development
- Bachelor of Arts in Game Design
- Master of Science in Human-Computer Interaction

Jamie later served as an adjunct instructor at Grand Canyon University, allowing her to experience university curriculum from both the development and teaching perspectives.

# Course Map Development Process

## What is a degree course map?

A degree course map defines how students progress through an academic program.

It identifies:

- Required courses
- Course sequencing
- Prerequisites
- Credit distribution
- Skill progression
- Program milestones
- General education integration
- Capstone preparation
- Graduate-level expectations

Jamie approached course mapping as a systems-design problem.

Each course needed a clear role within the program, and each major competency needed to be introduced, practiced, reinforced, and assessed before graduation.

## Jamie’s Course Mapping Method

Jamie’s process included:

1. Defining graduate capabilities
2. Identifying core program competencies
3. Grouping competencies into major learning domains
4. Sequencing skills from introductory to advanced
5. Identifying prerequisite relationships
6. Defining the purpose of each course
7. Mapping outcomes across the degree
8. Identifying signature projects
9. Planning capstone readiness
10. Reviewing the map for gaps, overlap, and unnecessary repetition

## Example Course Listing: Gameplay Programming

### Course Description

This course introduces students to the implementation of gameplay systems using a modern game engine. Students develop interactive mechanics, character systems, input controls, game states, and reusable gameplay components while applying object-oriented programming and debugging practices.

### Example Learning Objectives

By the end of the course, students should be able to:

- Implement reusable gameplay systems
- Apply object-oriented programming in a game-engine environment
- Create player input and character-control systems
- Debug gameplay behavior
- Use events, components, and state-based logic
- Evaluate gameplay code for maintainability and performance

### Example Signature Project

Students develop a playable vertical slice containing:

- Player movement
- Input handling
- Interactive objects
- A gameplay objective
- User-interface feedback
- Win and failure states
- Technical documentation

# Example Course Listing: Level Design

### Course Description

This course examines the principles and processes used to design effective game levels. Students explore spatial composition, player guidance, pacing, challenge progression, environmental storytelling, and iterative playtesting.

### Example Learning Objectives

Students should be able to:

- Design levels around defined player goals
- Apply pacing and difficulty progression
- Use visual and spatial cues to guide players
- Create blockouts and playable prototypes
- Conduct structured playtests
- Revise designs based on player feedback

### Example Signature Project

Students design, prototype, test, and refine a complete game level supported by:

- A level-design document
- Player-flow diagrams
- A playable blockout
- Playtesting notes
- A final design rationale

# Example Course Listing: Usability Testing

### Course Description

This graduate course introduces methods for evaluating the usability of interactive systems. Students plan and conduct usability studies, collect qualitative and quantitative data, identify usability issues, and communicate research findings.

### Example Learning Objectives

Students should be able to:

- Define research questions
- Recruit appropriate participants
- Facilitate moderated usability sessions
- Analyze qualitative and quantitative findings
- Prioritize usability problems
- Present evidence-based recommendations

### Example Signature Project

Students conduct a usability study of an interactive product and produce:

- Observation notes
- Findings

- Design recommendations
- Executive presentation
